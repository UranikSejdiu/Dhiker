# Dhikr Counter Laravel — Project Overview

A Laravel + Vue (Inertia) dhikr tracking app with multi-language and theme support.

## Tech Stack

- **Framework**: Laravel 11 (PHP 8.3+)
- **Frontend**: Vue 3 (Composition API) + Inertia.js + Vite
- **CSS**: Tailwind CSS 3 + `tailwindcss-animate` + shadcn-vue (Reka UI)
- **UI Components**: shadcn-vue (Button, Dialog, Sheet, DropdownMenu)
- **Drag Reorder**: vue-draggable-plus (SortableJS) — touch + mouse
- **Auth**: Laravel Breeze + Socialite (Google OAuth)
- **PWA**: Service worker + manifest.json
- **DB**: MySQL (`dhikr_counter`)

## Key Architecture Decisions

### Sync Strategy
- **Offline-first**: Counter taps update local refs immediately. Server POST is fire-and-forget.
- **CSRF**: dhikrs/reorder and dhikrs/sync routes excluded from CSRF in bootstrap/app.php (sendBeacon + Axios POST).
- **Online guards**: `sync()` checks `navigator.onLine` before requesting. `online`, `focus`, and `visibilitychange` events trigger sync when pending.
- **Hard refresh** (`hardRefresh`): Clears localStorage `dhikr_sync`, then does `window.location.reload()`.

### Theme & Language
- Both stored in `localStorage` AND synced to user record via `SettingsController` PATCH.
- On load, server value takes priority over localStorage.
- Theme applies via CSS vars on `:root` (see `applyThemeVariables()`).
- UI colors come from the reactive `colors` computed (inline `:style`) AND/or Tailwind utility classes (shadcn CSS vars).

### Version Bump
- `bump-version.js` runs automatically before `vite build` (`"build": "node bump-version.js && vite build"`).
- Patch >= 10 rolls to minor bump, minor >= 10 rolls to major bump.
- Updates `package.json`, `resources/js/constants/version.js`, and `public/manifest.json`.

### Routing
- `/` → Login (redirects to dashboard if authenticated)
- `/dashboard` — Auth required, loads DhikrController@index
- `/dhikrs` — CRUD routes (store, update, destroy)
- `/dhikrs/reorder` — POST, bulk sort_order update
- `/dhikrs/{dhikr}/reset` — POST
- `/dhikrs/sync` — POST, bulk sync endpoint
- `/settings` — PATCH for theme/language
- `/auth/google` + `/auth/google/callback` — Google OAuth

### UI Components (shadcn-vue)
- **Button** — `@/Components/ui/button`
- **Dialog** — `@/Components/ui/dialog` (Add/Edit modal + Confirm dialog)
- **Sheet** — `@/Components/ui/sheet` (Dhikrs list + Settings panels)
- **VueDraggable** — `vue-draggable-plus` for touch+mouse reorder with `.drag-handle` selector

### Drag Reorder
- Uses SortableJS via `vue-draggable-plus` — works on mouse + touch natively
- Reorder handle: `.drag-handle` class on the ⠿ grip button
- `@end` event persists order to localStorage + immediate server POST
- On page load, server order (props.dhikrs sorted by sort_order) is used directly
- LocalStorage written as cache for offline, but never overrides server order on refresh
- Reorder uses Axios POST (not Inertia) to avoid full page render
